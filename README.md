# HexaSort Web

Казуальная головоломка на гекс-поле: раскладываешь стопки цветных фишек, соседи
одного цвета сливаются, блок из десяти сгорает и запускает цепную реакцию.
Один бесконечный забег на счёт — без уровней, таймера и рекламы.

**▶ Играть: https://023irene.github.io/hexasort-web/**

## Как играть

- Перетащи стопку из руки в свободную ячейку.
- Поставь рядом с таким же цветом — фишки объединятся. Если рядом сразу две
  одноцветные стопки, всё соберётся в твою ячейку.
- Блок из 10 фишек сгорает: 10 очков и 10 монет. Каждая фишка сверх десятой стоит
  вдвое дороже (13 фишек → 16 очков).
- Если сгорание освободило цвет, который тут же собрался и сгорел снова, — это
  комбо. Каждое следующее звено цепочки приносит бонусные монеты.
- Поле растёт кольцами по счёту, вместе с ним прибавляется по три новых цвета:
  4 → 7 → 10.
- Монеты тратятся на бусты: перенести стопку (25), пересдать руку (30),
  убрать лишнюю стопку (40).
- Поле можно вращать перетаскиванием — после отпускания оно доворачивается до грани.
- `R` — начать заново, `Esc` — отменить буст.

Игра заканчивается, когда свободных ячеек не осталось, а в руке ещё есть стопки.

## Технически

Вся игра — **один файл `index.html`**: ванильный JavaScript и Canvas 2D, ноль
зависимостей, ни сборки, ни сервера. Открывается двойным кликом и работает офлайн.

```
index.html            вся игра
tests/core.test.js    тесты ядра (331 проверка)
```

**Тесты:** `node tests/core.test.js` — код выхода 0 означает, что всё зелёное.
Тест выполняет игровой `<script>` в Node с заглушками браузера, поэтому проверяет
ровно тот файл, который открывает игрок.

**Отладка:** `index.html?seed=42` — воспроизводимый расклад. В консоли доступны
`__GAME_STATE__` и `render_game_to_text()`.
